<h3 align="center">Building in public, learning out loud.</h3>

I spend most of my days wiring together Terraform plans, Kubernetes manifests, and Bash scripts so that deploys stop being someone's 2am problem. Lately I've been drawn to the quieter parts of DevOps — the tooling nobody notices when it works, the automation that feels less like magic and more like a well-kept habit. Singapore-based, still curious, still occasionally breaking staging.
